Key Insights:
--------------------------------------------------------------------------------
1. Supervised learning uses labels directly, so it achieves higher
   accuracy than unsupervised clustering's Hungarian matching.

2. However, clustering validated the embedding quality WITHOUT labels,
   which guided feature engineering (domain extraction, layer selection).

3. Both use the same embeddings (domain ESM-2, layers 20-33 averaged),
   demonstrating that better unsupervised separability predicts better
   supervised performance.
